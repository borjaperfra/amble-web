# amble-web

The public website for **Amble** — your professional Rep.

This project is deliberately separate from the product repo (`../amble`). Nothing here imports from, writes to, or runs inside that directory.

## Source of truth

The product and brand are defined in the Amble repo. Read them before designing or writing copy:

- `../amble/PRODUCT_SPEC.md` — what Amble is, voice, the candidate journey, what we don't build.
- `../amble/DESIGN_SYSTEM.md` — palette, typography (Newsreader + Inter), spacing, motion, signature details.

See [`BRIEF.md`](./BRIEF.md) for the summary that matters to the website.
